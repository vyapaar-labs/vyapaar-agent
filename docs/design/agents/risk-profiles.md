# Vyapaar Risk Profiles Framework

Vyapaar defines five canonical risk profiles for portfolio construction, position sizing, and risk enforcement across the trading and investment lifecycle.

---

## 1. Conservative
**Objective**: Capital preservation · **Horizon**: 3+ years  
**Philosophy**: Preservation of nominal and real capital: high allocation to sovereign debt, liquid instruments, and fixed income, small equity sleeve, strict drawdown limits.

| Metric | Target / Limit |
| :--- | :--- |
| **Max Single Position** | 5% |
| **Max Drawdown Limit** | 10% |
| **Target Volatility** | 6% annualized |
| **Cash & Liquid Assets** | 10% – 30% |
| **Equity Sleeve** | 10% – 25% (Large-cap / Index only) |
| **Debt & Sovereign Gold** | 65% – 80% |
| **Leverage** | Strictly prohibited (1.0x max) |

---

## 2. Moderately Conservative
**Objective**: Income with modest growth · **Horizon**: 5+ years  
**Philosophy**: Stable income generation with conservative capital growth: quality fixed income leads, meaningful large-cap dividend equity sleeve, controlled downside.

| Metric | Target / Limit |
| :--- | :--- |
| **Max Single Position** | 7% |
| **Max Drawdown Limit** | 15% |
| **Target Volatility** | 9% annualized |
| **Cash & Liquid Assets** | 5% – 20% |
| **Equity Sleeve** | 25% – 45% (High-dividend / Large-cap) |
| **Debt & Fixed Income** | 50% – 65% |
| **Leverage** | Strictly prohibited (1.0x max) |

---

## 3. Moderate
**Objective**: Balanced wealth accumulation · **Horizon**: 7+ years  
**Philosophy**: Balanced capital appreciation and volatility management: well-diversified multi-asset mix across Indian equities (Nifty 50, Nifty Next 50), bonds, and gold.

| Metric | Target / Limit |
| :--- | :--- |
| **Max Single Position** | 10% |
| **Max Drawdown Limit** | 20% |
| **Target Volatility** | 12% annualized |
| **Cash & Liquid Assets** | 3% – 15% |
| **Equity Sleeve** | 50% – 70% (Large and Mid-cap blend) |
| **Debt & Gold (SGB/ETF)** | 25% – 40% |
| **Derivatives / Hedging** | Defensive index put options / covered calls permitted |
| **Leverage** | None (1.0x) |

---

## 4. Moderately Aggressive
**Objective**: Capital appreciation · **Horizon**: 10+ years  
**Philosophy**: Growth-focused equity portfolio: high equity exposure across large, mid, and quality small caps, with a tactical buffer in liquid assets for market dips.

| Metric | Target / Limit |
| :--- | :--- |
| **Max Single Position** | 12% |
| **Max Drawdown Limit** | 30% |
| **Target Volatility** | 16% annualized |
| **Cash & Liquid Assets** | 2% – 10% |
| **Equity Sleeve** | 75% – 90% (Large, Mid, and Small-cap) |
| **Tactical Allocations** | Up to 15% in factor/momentum strategies |
| **Leverage** | None for cash portfolios; strictly regulated margin for active strategies |

---

## 5. Aggressive
**Objective**: Maximum long-term compound growth · **Horizon**: 15+ years  
**Philosophy**: Maximum wealth compounding: nearly all equity, factor strategies, sector momentum, and high tolerance for multi-quarter cyclical drawdowns.

| Metric | Target / Limit |
| :--- | :--- |
| **Max Single Position** | 15% |
| **Max Drawdown Limit** | 40% |
| **Target Volatility** | 22% annualized |
| **Cash & Liquid Assets** | 0% – 10% |
| **Equity Sleeve** | 85% – 100% (High-beta, Small-cap, Momentum) |
| **Quantitative Alpha** | High allocation to automated rule-based strategies |
| **Drawdown Tolerance** | High; strict rebalancing on systematic signals |
